This is a collection of scripts for detailed tracking of instrument bookings using the "list of sessions" data from PPMS. 

The file contains scripts to:
Load data
Filter and re-order data
Summarize usage and income per month, quarter, year
Visualize usage:
  Bookings per instrument
  Bookings per instrument type
  Income per instrument
  Comparing income and costs
  
Analyze cancellations

Analyze booked hours versus used hours for each user

The scripts are now very well annotated right now and will need some adaptation depending on your local setup. Please do not hesitate to contact us.
